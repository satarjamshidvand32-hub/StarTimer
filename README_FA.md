# پروژه Star Timer برای اندروید

این پروژه یک تایمر آزمایشی اندروید با بازه ۱ تا ۱۰۰۰ میلی‌ثانیه است.

## امکانات
- تنظیم فاصله با اسلایدر
- شروع و توقف
- شمارنده دفعات اجرای تایمر
- صفر کردن شمارنده

## ساخت APK فقط با گوشی از طریق GitHub
1. فایل ZIP را از حالت فشرده خارج کنید.
2. در github.com وارد حساب شوید و یک مخزن جدید بسازید.
3. همه محتویات پوشه پروژه را در ریشه مخزن بارگذاری کنید؛ پوشه مخفی `.github` نیز باید بارگذاری شود.
4. از زبانه Actions، گردش‌کار Build Android APK را اجرا کنید.
5. پس از پایان موفق، در همان اجرای Action قسمت Artifacts را باز کنید و `StarTimer-debug-apk` را دانلود کنید.
6. ZIP خروجی را باز کنید و فایل `app-debug.apk` را روی گوشی نصب کنید.

## محدودیت
این برنامه فقط تایمر آزمایشی است؛ اتوکلیک واقعی، پنل شناور، دسترسی Accessibility و اتصال به کارگزاری ندارد.
اندروید زمان‌بندی دقیق و تضمینی ۱ میلی‌ثانیه را تضمین نمی‌کند.
